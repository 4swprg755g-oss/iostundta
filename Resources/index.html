🩹 Hex Auto-Sync Patcher

Nạp file → dán offset + hex (hoặc hex => hex) → file tự động được vá ngay. Không cần bấm nút.

1 · File nguồn chưa nạp

2 · Dán Offset + Hex ● đang đồng bộ

Mỗi dòng một lệnh — dán vào là file tự cập nhật. Hỗ trợ: 0x1A2B DE AD · 1A2B: DE AD · 1A2B - DE AD · 00001A2B  DE AD BE EF  |ascii|
Dạng HEX_TÌM => HEX_THAY sẽ quét toàn file và thay mọi vị trí khớp. Patch trực tiếp chạy trước, sau đó quy tắc thay thế quét trên kết quả.
